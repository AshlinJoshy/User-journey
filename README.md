# Real Estate Journey Planner

A visual tool to map out customer journeys for real estate digital marketing campaigns. Built with Next.js and React Flow.

## Features

- **Drag & Drop Interface**: Easily drag nodes from the sidebar to the canvas.
- **Node Categories**:
  - **Sources**: Meta Ads, Google Ads, Organic Posts.
  - **Pages**: Landing Pages, Property Listings.
  - **Actions**: Link Clicks, Form Submissions.
  - **Channels**: WhatsApp, Email.
  - **Logic**: Delays, Conditions.
- **Visual Mapping**: Connect nodes to define the user flow.
- **Configuration**: Click on a node to edit its label, target audience, and description.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open**: [http://localhost:3000](http://localhost:3000)

## Deployment

The project is ready to be deployed on Vercel.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Visualization**: React Flow (@xyflow/react)
- **Icons**: Lucide React
